# Local run outputs

Place experiment reports, predictions, model bundles and staged serving payloads
in new subdirectories here. Only this guide and the placeholder belong in Git.
Preserve existing run receipts and artifacts; they may be required for evaluation
or comparison.

For a trusted bundle, use the [deployment guide](../deployment/README.md).
Use the allowlisted release staging command for public serving files; do not
publish this directory wholesale. Raw predictions, private splits, image paths
and unselected trials stay local.
